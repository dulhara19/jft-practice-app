Dulhara
Lakshan author · designer · developer

Software Engineer · AI/ML Tutor · Web Developer. Built JFT-Basic Practice from the ground up — the question bank, the parser, the UI, and every line of code you're looking at.

The 5 mock papers, the Irodori-derived decks, the bilingual explanations, and the entire codebase are original work. This app is a passion project for Japanese learners preparing for the JFT-Basic exam.
